# 🏠 Cian Flat Parser — Парсер планировок квартир

Мини-парсер объявлений с **cian.ru**, который автоматически скачивает фотографии квартир и с помощью компьютерного зрения + OCR **находит среди них планировку** (поэтажный план).

---

## 📋 Что делает проект

1. **`1_downloader.py`** — открывает Cian (через Playwright), проходит по страницам выдачи в выбранных регионах, собирает ссылки на новые объявления (которых нет в `seen_offers.txt`) и скачивает все изображения в папку `all_photos/<offer_id>/`.
2. **`2_analyzer.py`** — следит за папкой `all_photos`, дожидается маркера `.download_complete` и анализирует каждое фото. Лучший кандидат на «планировку» копируется в `RESULT_PLANS/`, а сама папка объявления переносится в `CHECKED/` или `NOT_FOUND/`.

---

## 📁 Структура проекта
```text
project/
├── 1_downloader.py # Скачивание фото с объявлений
├── 2_analyzer.py # Поиск планировки среди фото
├── seen_offers.txt # Уже обработанные URL (чтобы не скачивать повторно)
│
├── all_photos/ # Сюда качаются фото (папка на каждый offer_id)
│ └── 330113720/
│ ├── 330113720_00.jpg
│ ├── 330113720_01.jpg
│ └── .download_complete # маркер завершения загрузки
│
├── RESULT_PLANS/ # Найденные планировки: <offer_id>_plan.jpg
├── CHECKED/ # Обработанные объявления (планировка найдена)
└── NOT_FOUND/ # Обработанные объявления (планировка не найдена)
```

## ⚙️ Установка

### 1. Python-зависимости

```bash
pip install playwright requests opencv-python numpy pillow pytesseract
playwright install chromium
```

### 2. Tesseract OCR
Анализатор использует Tesseract для распознавания текста (рус + англ).

Windows: скачать установщик с https://github.com/UB-Mannheim/tesseract/wiki (обязательно отметить пакет Russian), затем раскомментировать путь в 2_analyzer.py:

```python
pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'
```
Linux:
```bash
sudo apt install tesseract-ocr tesseract-ocr-rus
```

macOS:
```bash
brew install tesseract tesseract-lang
```

## 🚀 Запуск
Запускать нужно в двух терминалах — скачивание и анализ работают параллельно.

Терминал 1 — загрузчик:

```bash
python 1_downloader.py
```
Терминал 2 — анализатор:

```bash
python 2_analyzer.py
```
Анализатор сам подхватывает новые папки по мере их появления (проверка каждые 3 секунды).

## 🧠 Как анализатор определяет планировку
Для каждого изображения считается рейтинг:

| Критерий | Влияние |
| --- | --- |
| Яркие насыщенные цвета (фото интерьера) | −20 |
| Много белого / светлого фона | +10 |
| Графичные тайлы (белый фон + тонкие линии, как на чертеже) | +10 |
| Найденные ключевые слова (спальня, кухня, санузел, м², этаж …) | +3 за слово |
| Числа с дробью (площади, напр. 12,5) | +1 за число |

Лучшее фото с рейтингом ≥ 10 сохраняется как **`<offer_id>_plan.jpg`**. Иначе папка уходит в **`NOT_FOUND`**.

Список ключевых слов настраивается в PLAN_KEYWORDS в **`2_analyzer.py`**.

## 🔧 Настройка
### Регионы поиска (**`1_downloader.py`**)
```python
REGION_IDS = [1, 2, 474, 460]
```
1 — Москва

2 — Санкт-Петербург

474 — Московская область

460 — Ленинградская область

ID других регионов можно найти в URL выдачи Cian (&region=...).

### Паузы между запросами
В **`1_downloader.py`**: await asyncio.sleep(1.5) после объявления, await asyncio.sleep(3) после страницы — не снижайте сильно, чтобы не получить бан.

### Порог принятия планировки (2_analyzer.py)
```python
if best_file and max_rating >= 10.0:
```

## 🛡️ Защита от повторной обработки
**`seen_offers.txt`** — список уже скачанных URL. Удалите строку, чтобы перекачать объявление.

Папка <offer_id> в **`all_photos`** — если существует, загрузчик её пропустит.

Файл **`.download_complete`** — сигнал анализатору, что загрузка завершена; удаляется сразу после начала анализа.

## ⚠️ Ограничения

- Селекторы Cian (`data-name="CardComponent"`, `GalleryInnerComponent` и т.п.) могут измениться при редизайне — тогда нужно править `selectors` в `1_downloader.py`.
- Эвристика планировок не идеальна: чертежи с цветной заливкой или фото интерьера с текстом могут давать ложные срабатывания.
- Для работы нужен стабильный интернет и доступ к `cian.ru` (возможны капчи при частых запросах).
