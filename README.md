# Cian Flat Parser → Roboflow

Пайплайн из двух этапов: скачивание фотографий объявлений с Cian, локальный анализ изображений и отправка **одного лучшего кандидата** в датасет Roboflow.

## Архитектура

Пайплайн состоит из двух независимых процессов, работающих параллельно и обменивающихся состоянием через файловую систему:

| Этап | Модуль | Назначение |
|------|--------|-----------|
| 1. Сбор данных | `1_downloader.py` | Проходит по выдаче Cian, обнаруживает новые объявления и сохраняет фотографии в `all_photos/<offer_id>/`. По завершении создаёт маркер `.download_complete`. |
| 2. Анализ и загрузка | `2_analyzer.py` | Анализирует изображения, выбирает файл с наибольшим рейтингом и, если рейтинг не ниже порога `MIN_PLAN_RATING`, отправляет его в Roboflow. |

Маркер `.download_complete` — единственный сигнал для анализатора о готовности объявления к обработке. Такая схема позволяет перезапускать оба процесса независимо друг от друга без потери состояния.

### Жизненный цикл объявления

```
Cian → all_photos/<offer_id>/ → [анализ] ─┬─► загрузка в Roboflow → CHECKED/
                                          └─► рейтинг ниже порога  → NOT_FOUND/
```

- **Успешная загрузка** — папка объявления переносится в `CHECKED/`.
- **Планировка не найдена** (рейтинг ниже `MIN_PLAN_RATING`) — папка переносится в `NOT_FOUND/`.
- **Ошибка Roboflow** — папка и маркер `.download_complete` остаются в `all_photos/`; анализатор повторит попытку при следующем запуске.

## Требования

- Python 3.10+
- Playwright (Chromium)
- Tesseract OCR с языковыми пакетами `rus` и `eng`

## Установка

```bash
pip install -r requirements.txt
playwright install chromium
```

### Tesseract

**Windows.** Установите Tesseract с языком Russian. При необходимости пропишите путь к исполняемому файлу в `2_analyzer.py`:

```python
pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'
```

**Ubuntu / Debian:**

```bash
sudo apt install tesseract-ocr tesseract-ocr-rus tesseract-ocr-eng
```

**macOS:**

```bash
brew install tesseract tesseract-lang
```

## Настройка Roboflow

1. Скопируйте `.env.example` в `.env`.
2. Заполните параметры доступа.

```env
ROBOFLOW_API_KEY=your_api_key
ROBOFLOW_WORKSPACE=your_workspace_id
ROBOFLOW_PROJECT=your_project_id
USER_AGENT=Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36
```

> **Безопасность.** Файл `.env` добавлен в `.gitignore` и не должен попадать в репозиторий. Не публикуйте API-ключ Roboflow и не передавайте его третьим лицам.

## Запуск

Оба процесса запускаются одновременно, каждый в своём терминале, из корня проекта.

**Терминал 1 — загрузчик:**

```bash
python 1_downloader.py
```

**Терминал 2 — анализатор:**

```bash
python 2_analyzer.py
```

Останавливать процессы можно в любом порядке: состояние сохраняется на диске, при следующем запуске обработка продолжится с того же места.

## Конфигурация

Параметры, задаваемые в коде:

| Файл | Параметр | Назначение | Значение по умолчанию |
|------|----------|-----------|----------------------|
| `1_downloader.py` | `REGION_IDS` | Список ID регионов Cian для обхода выдачи | `[1, 2, 474, 460]` |
| `2_analyzer.py` | `MIN_PLAN_RATING` | Минимальный рейтинг изображения для отправки в Roboflow | `10.0` |

## Переменные окружения

Файл `.env.example` содержит следующие ключи:

| Переменная | Описание |
|-----------|----------|
| `USER_AGENT` | User-Agent браузера, используемого в Playwright. Должен соответствовать реальному отпечатку браузера, иначе сайты с anti-bot защитой (Cloudflare и подобные) могут блокировать запросы. Эталонные значения — в [документации Playwright](https://playwright.dev/docs/emulation#user-agent). |
| `ROBOFLOW_API_KEY` | Приватный ключ Roboflow (Profile → Settings → API Keys). |
| `ROBOFLOW_WORKSPACE` | ID (slug) воркспейса Roboflow — сегмент URL после `app.roboflow.com/`. |
| `ROBOFLOW_PROJECT` | ID (slug) проекта Roboflow — сегмент URL после воркспейса. |

## Повторные попытки и идемпотентность

При ошибке загрузки в Roboflow папка объявления **не** переносится в `CHECKED/`, а маркер `.download_complete` сохраняется — анализатор повторит попытку при следующем запуске.

Если сервер Roboflow принял изображение, но соединение прервалось до получения ответа, повторная попытка может создать дубликат в датасете: SDK не предоставляет гарантированного ключа идемпотентности. Учитывайте это при проверке данных.
